# Moodify

Moodify is a modern web app that recommends songs and playlists based on your current **mood** and **music genre preferences**. Powered by the Spotify API and built with React, it delivers a tailored listening experience through a clean and responsive interface.

## Features

- Song and playlist recommendations based on selected mood and genre
- Toggle between song and playlist search modes
- Built-in Spotify player integration
- Fully responsive design for mobile and desktop
- Spotify OAuth 2.0 login & session handling

---

## Tech Stack

- **Frontend**: React
- **Backend**: Spring Boot, Maven
- **API**: Spotify Web API
- **Auth**: Spotify OAuth 2.0
- **Styling**: Custom CSS

---

## 📦 Getting Started

```bash
git clone https://github.com/sue-btis/moodify.git
cd moodify
npm install
npm start
```

> Make sure to configure your Spotify credentials in a `.env` file based on `.env.example`.
